## ① 今月やること

### 1. 最低賃金が11月・12月に発効する県があります

令和8年度の地域別最低賃金は、都道府県ごとに順次発効しています。**10月中に発効した地域のほかに、11月・12月に発効する県があります。**

**すでに発効した県**（11月分の給与計算で単価が変わります）

| 発効日 | 都道府県 | 改定後の時間額 |
|---|---|---|
| 11月1日 | 山梨 | 1,113円 |
| 11月1日 | 徳島 | 1,103円 |
| 11月1日 | 愛媛 | 1,093円 |
| 11月1日 | 大分 | 1,096円 |
| 11月2日 | 長崎 | 1,087円 |

**これから発効する県**

| 発効日 | 都道府県 | 改定後の時間額 |
|---|---|---|
| **11月15日** | **佐賀** | **1,095円** |
| **11月16日** | **京都** | **1,180円** |
| 12月1日 | 岩手 | 1,090円 |
| 12月1日 | 熊本 | 1,092円 |
| 12月2日 | 沖縄 | 1,086円 |

**ここに落とし穴が1つあります。**

佐賀（11月15日）と京都（11月16日）は、**月の途中からの発効**です。つまり、**同じ月の給与の中で、前半と後半で下回ってはいけない金額が変わります。** 月をまたいで切り替えると、発効日から月末までの分が最低賃金割れになります。

該当する県に事業場がある場合は、**11月分の給与計算が、発効日の前と後で分けて計算できているか**をご確認ください。

→ [地域別最低賃金の全国一覧（厚生労働省）](https://saiteichingin.mhlw.go.jp/table/page_list_nationallist.php)

### 2. パート・アルバイトの「週の所定労働時間」を一覧にしておく

②でお伝えする社会保険の話は、**最後はこの数字だけで決まります。** 年度末や4月に慌てて調べることになるので、今のうちに一覧にしておくと後が楽です。

一覧にしていただきたいのは3つだけです。

| 見るもの | 注意点 |
|---|---|
| **雇用契約書に書いてある週の所定労働時間** | 実際のシフトではなく、**契約書・就業規則に書いてある時間**で判断します |
| 通常の労働者の週の所定労働時間 | これの4分の3が基準になります（下記②） |
| 契約を更新しているか、2か月を超えて働く見込みがあるか | — |

**契約書の時間と実際の勤務が長くずれている方**がいたら、そこが先に手を入れるところです。社会保険だけでなく、有給休暇の日数や割増賃金の単価にも関わります。

### 3. 年末年始の休日カレンダーを確定させる

11月のうちに決めておくと、12月の給与計算が楽になります。決めておきたいのは次の点です。

- 年末年始のどの日を**所定休日**とし、どの日を**法定休日**とするか
- その期間に出勤が発生した場合、**どの割増率になるか**
- 休日に出勤した方の**代休・振替休日**をどう扱うか

割増率は次のとおりです（労働基準法第37条）。

| 何に対して | 割増率 |
|---|---|
| 時間外労働 | **25%以上** |
| **1か月60時間を超える時間外労働** | **50%以上**（中小企業も2023年4月から対象です） |
| **法定休日**の労働 | **35%以上** |
| 深夜（22時〜翌5時）の労働 | 25%以上（時間外と重なれば加算されます） |

**法定休日ではない休日（所定休日）の出勤は、休日の割増ではなく時間外労働**として扱います。週40時間を超えた分に25%以上がつきます。

**年末年始で注意していただきたいのは、60時間の数え方です。**
1か月60時間の算定に、**法定休日の労働は含めません。** 一方で、**法定休日以外の休日に行った時間外労働は含めます。** 年末年始に出勤が続くと、ここで60時間を超えて50%になることがあります。

ここを決めずに12月を迎えると、割増の計算を後追いで直すことになります。

→ [時間外・休日労働と割増賃金（厚生労働省）](https://www.check-roudou.mhlw.go.jp/study/roudousya_jikangai.html)

## ② 制度のうごき：パート・アルバイトの社会保険

### 何が変わったか

**2026年10月1日から、短時間労働者が社会保険に加入するための「賃金要件」（所定内賃金が月額8.8万円以上）が撤廃されました。**

- 根拠：令和7年年金制度改正法（**令和7年法律第74号**）
- 「月8.8万円」という線は、もうありません

ただし、ここが大事なところです。

> **これだけで加入対象が一気に広がるわけではありません。**
> **企業規模の要件（従業員51人以上）は、まだ残っています。**

つまり **御社の規模によって、話がまったく変わります。**

### 撤廃後に残っている要件

パート・アルバイトの方が社会保険に加入するのは、次の全部に当てはまる場合です。

| | 要件 | 補足 |
|---|---|---|
| 1 | **勤め先が「特定適用事業所」等であること** | ＝従業員51人以上。または会社が任意で届け出た事業所（下記） |
| 2 | 所定労働時間・所定労働日数が**通常の労働者の4分の3未満** | 4分の3以上の方は、下記の「別の話」をご覧ください |
| 3 | **週の所定労働時間が20時間以上** | 契約書・就業規則上の時間で判断します |
| 4 | **学生ではない** | 休学中・定時制・通信制の方などは例外があります |
| 5 | **2か月以内の期間を定めて使用される方ではない** | — |

**今回なくなったのは、ここに入っていた賃金の要件です。** 残っている線は「週20時間」です。
**賃金の額が低いことを理由に対象から外れることは、もうありません。**

> **例外が1つあります。** 最低賃金法の減額特例の許可を受けていて、所定内賃金が月額8.8万円未満の方（特定減額特例対象者）は、原則として加入対象外です。ただし、**ご本人の申出により加入することができます。**
>
> この「所定内賃金が月額8.8万円未満か」は、基本給と諸手当で判断し、**次のものは算入しません。**
> ①臨時に支払われる賃金（結婚手当など）／②1か月を超える期間ごとに支払われる賃金（賞与など）／③時間外・休日・深夜労働の割増賃金／④**精皆勤手当・通勤手当・家族手当**

### 「従業員51人」の数え方

ここは取り違えやすいところです。**全従業員の人数ではありません。**

| 項目 | 内容 |
|---|---|
| 数えるもの | **厚生年金保険の被保険者の数** |
| 数えないもの | **適用拡大で加入している短時間労働者は含めません** |
| 法人の場合 | **同一の法人番号のすべての事業所を合算**します（本店・支店・店舗を別々に数えません） |
| 個人事業所の場合 | 事業所ごとに数えます |
| 判定の仕方 | **1年のうち6か月以上、51人以上となることが見込まれるか**で判定します |
| 一度該当したあと | 50人以下に減っても、届出をするまでは特定適用事業所のままです |

### 御社が51人以上の場合

**10月以降、新たに加入対象になった方がいる可能性があります。**

週の所定労働時間が20時間以上で、これまで「月8.8万円に届かない」という理由で対象外だった方です。

この8.8万円は、**支給総額ではなく「所定内賃金」で判定する**ものでした。所定内賃金には、残業代や賞与、通勤手当などを含めません（算入しない賃金の具体的な範囲は、ひとつ上の特定減額特例の箇所に挙げたとおりです）。
そのため、**手当を含めた支給総額では9万円を超えていても、判定上は8.8万円に届いていなかった方**がいます。その方が10月から対象です。

**週20時間以上の方の一覧を作って、加入漏れがないかご確認ください。**

### 御社が50人以下の場合 — 関係するのはこの2つです

**今回の改正によって、新たに加入させる義務が生じることはありません。** ただし、別の2点が関係します。

#### （1）「4分の3以上」の方は、規模に関係なく加入対象です

これは適用拡大とは**別の話**で、以前から変わりません。

> **所定労働時間・所定労働日数が通常の労働者の4分の3以上ある方は、「短時間労働者」ではなく通常の被保険者として、会社の規模にかかわらず加入対象です。**

週40時間の会社であれば、**週30時間以上働いている方**が該当します。
「うちは50人以下だから、パートは社会保険に入れなくていい」という理解は誤りです。ここは適用拡大の話が報道されるたびに混乱が起きるところなので、**この機会に一度ご確認ください。**

（なお、法人は従業員がいなくても適用事業所になります。個人事業所は常時5人以上が原則ですが、サービス業の一部・農業・漁業等は除かれます。）

#### （2）保険料を軽くする制度が、10月1日から始まりました

**これが今回、50人以下の会社にとって一番大きい話です。**

「社会保険に入ると手取りが減るので、働く時間を抑えたい」と言われたことのある会社は多いと思います。そこに向けた仕組みが始まりました。

**保険料調整制度**（2026年10月開始）です。

| | 内容 |
|---|---|
| 何が起きるか | **短時間労働者本人の健康保険料・厚生年金保険料が軽くなります** |
| 期間 | **申出をした月から通算3年間**（3年目は軽減の幅が1〜2年目の半分） |
| 本人の負担 | 標準報酬月額88,000円の方：1〜2年目は本人25％・会社75％（通常は50％ずつ）。標準報酬月額126,000円の方：本人48％・会社52％ |
| 会社の負担 | 会社が差額を**いったん多く納め、3か月後の保険料から差し引いて還付**されます。**最終的に会社が納める保険料は増えません** |
| 本人の年金額 | **減りません** |
| 対象者 | 短時間労働者として加入する方で、**標準報酬月額126,000円以下**の方 |

**どういう会社が使えるか。**

50人以下の会社の場合、**2026年10月1日から2035年9月30日までの間に「任意特定適用事業所」になった**ときに使えます。

**任意特定適用事業所**とは、従業員51人以上でなくても、**会社が自分から届け出て、パート・アルバイトを社会保険に加入させることにした事業所**のことです。届出には同意が必要で、要件は次のとおりです。

| 項目 | 内容 |
|---|---|
| 同意を得る相手（同意対象者） | **厚生年金保険の被保険者、70歳以上被用者、短時間労働者** |
| 同意の要件（いずれか1つ） | ①同意対象者の過半数で組織する労働組合の同意／②同意対象者の過半数を代表する者の同意／③**同意対象者の2分の1以上の同意** |
| 提出書類 | 健康保険・厚生年金保険 任意特定適用事業所申出書＋同意を証する書類 |
| 提出先・方法 | 事務センターへの郵送、または管轄の年金事務所の窓口 |
| 効力の発生日 | **申出が受理された日**が、特定適用事業所に該当した日・短時間労働者の資格取得日になります |

なお、**やめる（取消しの）申し出には、同意対象者の4分の3以上の同意が必要**です。入るときより重くなっています。

> ### ここに期限があります
>
> **2026年10月1日の時点ですでに任意特定適用事業所になっている会社は、この制度の対象外です。**
> **これから届け出る会社だけが使えます。**
>
> 申出の期限は、**制度を使えるようになった日から2年を経過した日が属する月の前月まで**です。
> （例：2026年10月に任意特定適用事業所になった場合 → 2028年9月末まで）
>
> 届出は **事務センターへの郵送か、管轄の年金事務所の窓口**です。

**使うときの注意点が3つあります。**

1. **事業所単位です。** 対象になる方の一部だけを選んで使うことはできません。全員に適用されます
2. **途中でやめられません**（制度が自動で停止される場合はあります）
3. **保険料を納期限までに納めず、督促状の期限までにも納めなかった月は、追加負担分が還付されません**

### カレンダーに入れておく年

企業規模の要件は、ここから段階的に下がっていきます。公表されているスケジュールは次のとおりです。

| 時期 | 対象になる会社 |
|---|---|
| 2027年9月まで | 51人以上 |
| **2027年10月** | **36人以上**（36〜50人の会社が新たに対象） |
| **2029年10月** | **21人以上** |
| **2032年10月** | **11人以上** |
| **2035年10月** | **企業規模の要件がなくなります** |

**21人以上になる2029年10月**で、多くの会社が対象に入ります。
準備は「週の所定労働時間を一覧にする」ところから始まるので、**該当する年の前年の夏までに**一度棚卸ししておくのが現実的です。

あわせて、**2029年10月からは、個人事業所も業種にかかわらず、常時5人以上を使用する事業所が社会保険の対象になります**（現在は法律で定められた業種に限られています）。ただし、2029年10月の時点ですでにある事業所は当分の間対象外とされています。

## ③ 使える助成金：加入手続きの「前」に出す書類があります

**キャリアアップ助成金「短時間労働者労働時間延長支援コース」**です。

パート・アルバイトの方の**週の所定労働時間を延ばして、新たに社会保険に加入させた**場合に、助成を受けられるものです。いわゆる「年収の壁」の対策として設けられたものです。

### いくら出るか

**1年目（社会保険に加入させた時点の取組）**

| 週の所定労働時間の延長 | あわせて必要な賃上げ | 小規模企業 | 中小企業 | 大企業 |
|---|---|---|---|---|
| **5時間以上** | なし | **50万円** | **40万円** | **30万円** |
| 4時間以上5時間未満 | 5%以上 | 同じ | 同じ | 同じ |
| 3時間以上4時間未満 | 10%以上 | 同じ | 同じ | 同じ |
| 2時間以上3時間未満 | 15%以上 | 同じ | 同じ | 同じ |

**2年目（さらに次のいずれかを行った場合）**

| 要件（いずれか1つ） | 小規模企業 | 中小企業 | 大企業 |
|---|---|---|---|
| ①労働時間をさらに2時間延長する／②基本給をさらに5%以上増額する／③**昇給・賞与・退職金制度のいずれかの適用を新たに受けさせる** | **25万円** | **20万円** | **15万円** |

**いずれも従業員1人あたりの額で、申請できる人数に上限はありません。**
小規模企業なら、1年目と2年目で**1人あたり50万円＋25万円＝75万円**になります。

**「小規模企業」とは、支給申請の時点で、常時雇用する労働者の数が30人を常態として超えない事業主**です。30人を超える場合は、業種ごとの資本金・従業員数の基準で中小企業かどうかを判定します（卸売業なら資本金1億円以下または100人以下、小売業・飲食店なら5,000万円以下または50人以下、サービス業なら5,000万円以下または100人以下、その他は3億円以下または300人以下）。

### ここが一番の落とし穴です

> **キャリアアップ計画書を、社会保険の加入日の「前日まで」に都道府県労働局へ提出する必要があります。**
>
> **加入手続きを済ませてから気づくと、もう使えません。** 順序が決まっている助成金です。

延長のタイミングにも決まりがあります。**社会保険の加入日の1か月前以内に延長して加入させる**か、**加入日から2か月以内に延長する**かのどちらかです。
支給申請は、**取組を6か月間続けたあと、2か月以内**に行います。

### 誰が対象になるか

対象になる従業員の方は、次の**両方**に当てはまる方です。

1. **社会保険の加入日の6か月前の日以前から、続けて雇用されている**
2. **加入日から過去2年以内に、同じ事業所で社会保険に加入していなかった**

つまり、**新しく採用した方ではなく、今いる方の時間を延ばす**場合の制度です。

### もう使えなくなったものもあります

これまであった「**社会保険適用時処遇改善コース**」（手当等支給メニュー／労働時間延長メニュー／併用メニュー）は、**令和7年度（2025年度）末で終了しました。** 令和7年度末までに社会保険を適用した場合が対象で、令和8年度以降に適用した場合は対象になりません。
令和8年度以降は、上記の「短時間労働者労働時間延長支援コース」をご利用ください。

**労働時間を延ばすご予定がある場合は、手続きの前にご相談ください。** 計画書の提出が先か後かで、使えるかどうかが変わります。

## ④ よくあるご相談から

**ご相談**：「固定残業手当の時間数を増やしたいのですが、月給を変えずに増やして問題ありませんか」

**考え方**：**先に計算してみてください、とお願いしています。** かなりの確率で、最低賃金を下回ります。

固定残業手当（みなし残業手当）は、月給の中に何時間分の残業代が含まれているか、という形になっています。
ここで見落とされやすいのが、**時間数を増やすと、同じ月給でも時間あたりの単価が下がる**ことです。

実際にあったご相談では、月給を据え置いたまま時間数を大きく増やす予定になっていました。計算してみると、**予定していた時間数より少ない時間数でも、すでに最低賃金を下回っていました。** 最低賃金は毎年上がっているので、数年前に決めた金額のままでは足りなくなっていたのです。

ですので、ご相談のときは**2択**でお返ししています。

- **時間数を、計算上成り立つところまでに抑える**
- **時間数を増やすなら、月給も上げる**

そして、**固定残業手当は毎年の最低賃金の改定のたびに点検が必要**だということもお伝えしています。一度決めたら終わり、という性質のものではありません。

**①で最低賃金の発効日をご案内したのは、この点検とつながっています。** 発効日が来たら、固定残業手当のある方の時間単価をご確認ください。

## ⑤ 業務のひとこと：この手の確認を、AIに任せてよいところ／いけないところ

パート・アルバイトの方の一覧づくりは、表計算やAIに手伝わせると早く終わります。雇用契約書の内容を転記して、週の所定労働時間で並べ替えるところまでは任せてよい作業です。

ただ、**「この方が社会保険の加入対象かどうか」の判断は、AIに任せないでください。**

理由は単純で、**今回のように制度が切り替わった直後は、AIが古い情報で答えてしまう**ためです。「月8.8万円未満だから対象外です」という答えが返ってきても、それは2026年9月までの話です。

**AIに任せてよいのは「一覧をつくる」ところまで。「該当するかどうか」は人が決める。** この線を引いておくと、便利さだけ受け取れます。
