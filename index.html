FAQ

よくあるご質問

顧問契約には何が含まれますか？
add

日常の労務相談、社会保険・労働保険の手続き、法改正への対応などが基本に含まれます。プランによっては算定基礎届・年度更新や給与計算まで含まれますので、詳しくは料金表をご覧ください。

スポット（単発）だけの依頼もできますか？
add

可能です。就業規則の作成・見直しや助成金申請など、単発でのご依頼も承っています。料金の目安は料金表に記載していますので、あわせてご確認ください。

対応地域を教えてください。
add

東京都港区を拠点としています。オンラインでのご相談・お手続きに対応していますので、全国の企業さまからご依頼いただけます。

相談はどのように行いますか？
add

チャット・オンライン面談・対面のいずれにも対応しています。顧問先さまはチャットでのご相談が無制限ですので、日々の小さな疑問もお気軽にお寄せください。

クラウドソフトには対応していますか？
add

マネーフォワードをはじめとするクラウドの給与・会計・勤怠ソフトに対応しています。あわせて、AI活用による業務効率化のご支援も行っています。

研修や人材育成もお願いできますか？
add

可能です。社労士×キャリアコンサルタントとして、5名程度の少人数から500名規模まで、貴社に合わせた研修・人材育成をご提案します。まずは30分の無料相談で、お気軽にご要望をお聞かせください。
